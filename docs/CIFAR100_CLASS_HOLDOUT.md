# Frozen CIFAR-100 class-holdout study — 2026-09-28

This protocol is fixed before deriving the new class partition or training an 80-class model. Earlier CIFAR-100 images and other OOD tests have been inspected in the existing project; this is a prospective **new classifier/class-partition** experiment, not an untouched external benchmark. It tests whether the six already fixed post-hoc scores behave differently when ID and OOD images share the CIFAR-100 source and resolution. It cannot isolate semantic novelty perfectly or justify choosing a method from its test results.

## Class partition and populations

Use only the locally verified official CIFAR-100 Python archive. Determine the fine-to-coarse mapping from its **training** file, requiring exactly 100 fine labels, 20 coarse labels, five fine labels per coarse label, a unique coarse parent per fine label, and 500 training rows per fine label. For each coarse label in increasing numeric order, sort its five fine IDs, then use one shared `numpy.random.default_rng(2031)` stream and take the first element of `rng.permutation(fine_ids)` as that coarse group's held-out OOD fine class. The other four fine classes per group are ID. Save the 20 OOD fine IDs, 80 ID fine IDs, original fine-to-coarse map, RNG/library versions, archive/metadata hashes and all original row indices; independently regenerate the split before any model training. Never alter this split from validation or OOD scores.

Discard all 10,000 **training** images from the 20 held-out fine classes; they must not enter training, checkpoint selection, calibration, feature-bank fitting or tuning. The 80 ID classes contribute 40,000 official training rows. Within each ID fine class, use the existing stratified seed 2026 to choose 50 validation rows and 450 optimization rows, yielding 4,000 ID validation and 36,000 ID training images. Map sorted ID fine labels to contiguous classifier targets 0–79, keeping original fine/coarse labels in manifests. Within each ID class's 50 validation rows, use shared RNG seed 2029 and a fixed 20/15/15 draw for disjoint checkpoint/temperature/threshold roles: 1,600/1,200/1,200 total. Save original training-row indices for every role and independently verify disjointness and class counts.

Only after the class and validation partitions are frozen and audited may the official CIFAR-100 **test** file be read for final evaluation. Require its original 100 fine labels ×100 rows and the same fine-to-coarse mapping. Score all 8,000 ID-class test images and all 2,000 held-out-class OOD test images in original file order, with no filtering. ID/OOD source, 32×32 resolution and storage format are therefore matched. OOD prevalence for AUPR is 20%. The old 100-class classifier, old ID test scores and old thresholds are not reused in this new 80-class experiment.

## Fixed model, fit and evaluation

Train a fresh CIFAR-style ResNet-18 with 80 logits from scratch for seeds 0, 1 and 2. Use the same 100-epoch ID-only schedule as the completed isolation study: SGD momentum 0.9, learning rate 0.1, weight decay 5e-4, batch size 128, milestones after epochs 50/75/90, random crop with four-pixel zero padding, horizontal flip, CIFAR-100 channel normalization, AMP and deterministic algorithms on the verified Windows CUDA environment. Save exact split/source/config hashes, complete optimizer/scheduler/scaler and RNG state each epoch, all history and immutable selected checkpoint. Select the **first** epoch achieving the highest accuracy on the 1,600-row checkpoint ID role only. Train one GPU process at a time and resume only against matching source, split and config hashes.

Freeze all six original methods: MSP, Energy, MaxLogit, Entropy, normalized KNN-50 and pooled Mahalanobis with 1% shrinkage. Fit KNN and Mahalanobis only on all 36,000 optimization-ID features from each selected checkpoint. Evaluate T=1 and a temperature fitted only on the separate 1,200-row temperature-ID role. Calibrate 80/90/95/99% acceptance thresholds only on the other 1,200-row threshold-ID role. Do not train on held-out fine classes, use any OOD validation, or inspect OOD test scores to choose checkpoints, temperature, shrinkage, k, thresholds, method or report subset.

For every seed/method/temperature variant, save raw 80-logit vectors, 512-D features, original test indices and labels, predictions, all score vectors and fixed-threshold ID/OOD masks. Report ID-test classification accuracy, tied-pair AUROC, non-interpolated AUPR-out/in with 8,000/2,000 denominators, benchmark FPR95-ID using the ID **test** order statistic, and actual ID-test/OOD acceptance at each frozen ID-validation threshold. Preserve each seed point plus mean/sample SD. Independently audit split isolation, feature fits, scores, metrics, tie behavior, thresholds, counts, displayed values, source hashes and full regression. Partial pilots are not full results. This study changes both the trained classifier and ID label space relative to the previous 100-class runs, so cross-study numeric differences are descriptive, not a causal effect of source matching.
