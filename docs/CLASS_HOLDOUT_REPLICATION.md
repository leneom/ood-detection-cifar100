# Frozen class-partition replication v0.1 — 2026-09-28

## Motivation and inference boundary

The completed 80-ID/20-OOD same-source CIFAR-100 held-out-fine-class result uses one class partition, RNG seed 2031, with three full training seeds. Its 20-class heterogeneity and within-class image bootstrap do not measure how the result changes when **different fine classes** are held out. This replication fixes two additional partitions, shared class RNG seeds **2032 and 2033**, before deriving their labels or training any model. Together with the already completed 2031 partition, the intended design has three class partitions × three model-training seeds 0/1/2. All nine full 100-epoch schedules and independent audits are required before a partition-variability aggregate is called complete. The two new partitions were chosen after the first partition's test results were viewed; the exercise is robustness/sensitivity analysis, not untouched prospective external confirmation or a basis for a test-selected method.

## Fixed partitions and ID isolation

Use only the locally verified official CIFAR-100 Python training file for partitions. Recover its exact 100 fine / 20 coarse class map, five fine classes per coarse group and 500 training rows per fine class. For each new class RNG seed, use one `numpy.random.default_rng(class_seed)` stream, visit coarse groups in ascending numeric order, sort each group's five fine IDs and take the first of its `rng.permutation(fine_ids)` as the held-out OOD fine class. Do not change the seeds or reject a difficult class partition after inspecting its validation or test behavior. Require the two new partitions and old 2031 partition to have different OOD fine-ID sets; if the fixed seeds collide, preserve the attempt and declare an amendment **before any training or OOD scoring**.

For each split independently, discard all 10,000 held-out-class **training** rows. Of 40,000 ID training-file rows, use the original per-ID-fine-class stratified RNG 2026 to choose 50 validation and 450 optimization rows per class: 4,000 ID validation, 36,000 optimization ID. Apply shared role RNG 2029 to each ID class's 50 validation rows, assigning 20/15/15 to disjoint ID checkpoint/temperature/threshold roles: 1,600/1,200/1,200. Map sorted 80 ID fine labels to logits 0–79. Save original row indices, labels, class map, names, source hashes and random-generator versions. Independently regenerate both complete splits and role allocations before launching training. Do not read official test pixels during partition creation or trainer/checkpoint selection.

## Frozen model and scoring schedule

Each new partition trains **three fresh 80-class CIFAR-style ResNet-18** seeds 0, 1, 2, from random initialization. Reuse the already completed exact 100-epoch ID-only schedule: SGD momentum .9, LR .1, weight decay 5e-4, batch 128, milestones after epochs 50/75/90, zero-pad/crop/flip augmentation, CIFAR-100 normalization, AMP and deterministic algorithms on the verified Windows CUDA Python/GPU. Select the **first** best-accuracy checkpoint using only the 1,600 checkpoint-ID role. Save immutable selected and full resume checkpoints, source/config/partition hashes, all 100 trace rows and RNG states. Sequential GPU controller, one trainer process at a time, under the already recorded three two-second-spaced <=4,096 MiB VRAM / <=55% GPU / <=10% GPU-memory-utilization / <=55 W idle guard. Preserve/defer incomplete or busy attempts; never report a short pilot as a full model.

After each full three-seed partition is independently audited, use the complete official CIFAR-100 test file in original order: 8,000 new ID and 2,000 new held-out-class OOD rows. For every frozen checkpoint, save all logits, 512-D features, original row/class/prediction information, six pre-fixed scores (MSP, Energy, MaxLogit, Entropy, normalized KNN-50, 1%-shrinkage pooled Mahalanobis). Fit feature methods on that split's 36,000 optimization-ID features only. Fit temperature on its separate 1,200 temperature-ID rows and 80/90/95/99% acceptance thresholds on its separate 1,200 threshold-ID rows only. Report all six methods and T=1/ID-temperature variants: ID classification accuracy, AUROC, AUPR-out/in at 20% OOD prevalence, FPR95-ID from ID **test**, and actual ID-test/OOD-test acceptance under frozen ID-validation thresholds. Keep every split/seed point. No OOD-test value enters any training, fit, threshold, selection or method choice.
