# Frozen descriptive Tiny ImageNet class-heterogeneity analysis — 2026-09-28

This analysis is declared after the complete aggregate Tiny ImageNet result and before computing or inspecting any per-synset score/metric. It is explicitly **post-test descriptive analysis**, not a second held-out confirmation, an OOD validation set, or a basis for method, checkpoint or threshold selection. The original three-seed 10,000-image evaluation, all six methods, T=1/ID-temperature variants, ID scores and 80/90/95/99 thresholds remain immutable.

## Fixed strata and outputs

Use the archive's existing official validation annotation only as 200 lexical synset IDs with exactly 50 images each. Keep the all-image row order and bind it to the decoded cache and three raw extraction files. No classes are excluded, merged, reweighted, renamed, manually designated as semantically near/far, or used for fitting. Compare each 50-image synset to the identical complete 10,000-image CIFAR-100 ID-test score vector for each seed/method/variant.

For each of 200 synsets × three seeds × six methods × two variants, compute AUROC with half-credit ID/OOD ties. For each of the four pre-existing ID-validation thresholds, save the number of the 50 OOD images accepted and its rate. Save all 200 synset IDs, the exact 50 image indices per synset, all per-seed values and an unaltered copy or hash pointer to the source score/threshold arrays. Cross-check that the equal-weight mean of the 200 class AUROCs equals the original aggregate AUROC, and that class acceptance counts sum to each original full-OOD accepted count; this is possible because all classes have 50 images. Independently audit those identities and the per-class math.

For the descriptive report, show for each frozen method and variant only the 200-class distribution of the **three-seed mean** class AUROC and 95%-target OOD acceptance: median, 25th and 75th percentiles, minimum and maximum, with NumPy's linear percentile convention. Make two method-order-preserving plots showing these distributions. Do not rank synsets, designate “hard” or “easy” classes, select a method or infer class semantics from synset IDs. Keep all four thresholds and three seed values machine-readable. Do not compute classwise AUPR because comparing 50 OOD with 10,000 ID changes prevalence to about 0.5%, unlike the original aggregate 50% prevalence.

The 50-image stratum rates have a 2 percentage-point grid and are noisy. A shared ID test set and shared images create dependence across classes and methods. Quantiles describe observed classes only; they are not confidence intervals, training-seed uncertainty, or evidence that a detector has generalized to all future OOD populations. No additional GPU work, training, or external data is authorized by this diagnostic.
