## Data and disjoint roles

Save and hash the old indices/labels, and verify equality across all three original classifiers. No ID test, OOD test or synthetic-noise row enters the new train or validation partition.

With NumPy default_rng(2029), iterate classes 0..99. For each class, permute the 50 row positions within the original sorted 5,000 validation rows; assign the first 20 to checkpoint validation (2,000 total), next 15 to temperature fitting (1,500), last 15 to operational threshold calibration (1,500). The same three sets serve all training seeds. Every pair must be disjoint and their union exactly the original 5,000 rows.

Checkpoint validation images/labels select the maximum-accuracy epoch only; never use temperature-fit or threshold rows for checkpoint selection. Temperature fitting uses only its own 1,500 ID rows and the original phase-2 one-scalar log(T) NLL objective/bounds [0.05,20], xatol 1e-8/maxiter 200 and T=1 failure fallback. Threshold calibration uses only its own 1,500 ID rows and each frozen score, with the same inclusive tie/order-statistic rule at [0.80,0.90,0.95,0.99]. No threshold is adjusted for desired ID-test or OOD-test acceptance. Distinguish FPR95-ID's test-derived benchmark threshold from these operational validation thresholds.
