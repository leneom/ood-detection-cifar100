# Frozen Tiny ImageNet-200 held-out natural-OOD check — 2026-09-28

This declaration is written after completion of the three-way ID-validation isolation study and before downloading, decoding, feature extraction, or scoring any Tiny ImageNet image. The six primary detector formulas, three classifiers and all ID-fitted parameters are frozen. The goal is an additional previously unscored natural-OOD population for this local pipeline, not an OpenOOD leaderboard reproduction.

## Fixed population and integrity

Use the [Zenodo Tiny ImageNet archive, DOI 10.5281/zenodo.10720917](https://zenodo.org/records/10720917), file `tiny-imagenet-200.zip` from `https://zenodo.org/records/10720917/files/tiny-imagenet-200.zip?download=1`, with metadata size 248,100,043 bytes and MD5 `90528d7ca1a48142e341f4ef8d21d0de`. This is a mirror of the Stanford CS231n Tiny ImageNet challenge data, not an assertion that its archive bytes match an unavailable Stanford server copy. The [OpenOOD v1.5 overview](https://github.com/Jingkang50/OpenOOD/wiki/OpenOOD-v1.5-methods-%26-benchmarks-overview) identifies Tiny ImageNet-200 as near-OOD for CIFAR-100, but this local model, source split and preprocessing are different; no leaderboard comparability is claimed.

Only the archive's official `val/images` and `val/val_annotations.txt` supply OOD test images and integrity labels. Use all 10,000 unique validation filenames, sorted lexicographically, with no category filtering or OOD validation split. Require 200 synsets with 50 labeled validation images each, unique filename annotation and exactly 64×64 decodable images. Do not decode/train/score archive train or unlabeled test images. Reject unsafe archive paths, corrupted images, unexpected counts, archive digest mismatch and exact pixel duplicates against any existing CIFAR-100 train/validation/test image before scoring; preserve failure evidence, do not silently drop rows. OOD category labels are used only for these integrity counts and descriptive post-test reporting, never for model or detector fitting.

Decode every validation image with Pillow to RGB, resize 64×64 to 32×32 with `Image.Resampling.BILINEAR`, convert to uint8 CHW in the same channel order as the existing dataset loader, then apply the frozen CIFAR-100 normalization inside the existing feature extractor. No crop, flip, OOD-specific normalization or augmentation. Save sorted source names, synsets, original JPEG/SHA-256 byte hashes, resized pixel SHA-256, Pillow version and full cache hash. Any change to these rules needs a new declaration before viewing a Tiny ImageNet score.

## Frozen model, fit and scoring inputs

Use only the completed isolated CIFAR-100 seeds 0/1/2 and their immutable selected epochs 92/96/98. Their classifier checkpoints were selected solely on the disjoint 2,000-row ID checkpoint role. Reuse each seed's existing saved 45,000-ID-training feature bank, 10,000-ID-test logits/scores, 1,500-row ID temperature fit and 1,500-row ID threshold fit. Verify their source/array/partition/checkpoint hashes against the completed 17-input manifest. No retraining, alternate checkpoint, new ID/OOD fit, altered temperature, changed score direction, or threshold adjustment after the Tiny ImageNet images are read.

Compute exactly the original six primary methods: MSP, Energy, MaxLogit, Entropy, normalized feature KNN k=50 and pooled Mahalanobis with 1% shrinkage. Preserve T=1 logits scores plus the already ID-fitted temperature variant for MSP/Energy/Entropy; MaxLogit/KNN/Mahalanobis must be invariant across variants. KNN and Mahalanobis may be recomputed only from the frozen 45,000 ID training features with the original fixed implementation; save fit hashes and independently refit/query-audit. Retain every OOD logit, feature, score, classifier prediction, source filename, and all 80/90/95/99 acceptance masks.

## Fixed analysis and evidence boundary

Compare 10,000 ID-test versus the 10,000 Tiny ImageNet validation images; OOD is the positive class. For each seed, method and T=1/calibrated variant, report AUROC with half-credit ties, non-interpolated AUPR-out/in with 50% OOD prevalence, FPR95-ID and achieved ID-test acceptance at its benchmark threshold, and OOD acceptance under each of the four *already frozen ID-validation* thresholds with actual ID-test acceptance. Report all three individual seed points, mean and sample SD; retain counts and tie behavior. Do not select a winner or change a method based on this test. Noise remains a separate synthetic diagnostic and is not included here.

Independently audit the archive/pixel order, checkpoint/fit/threshold source hashes, all raw detector formulas, exact saved control scores, tie-aware metrics, operating masks and displayed report values; inspect scientific figures and run the full regression suite before declaring completion. This is a new OOD population for this project, but it remains one dataset with possible semantic overlap with CIFAR-100 and a 64→32 resolution shift. It cannot establish universal OOD generalization or isolate semantic from image-source/resolution effects. Keep the archive, decoded cache, raw outputs, figures and logs local; no external publication or communication.
