# Frozen Oxford-IIIT Pet test population extension — 2026-09-29

This is a sequentially chosen additional natural object-centric OOD population after viewing the original natural populations, Tiny ImageNet, Fashion-MNIST, class-holdout/RMD, Places365 and scene diagnostics. It is **not** an untouched method-selection set, a prospectively fixed multi-dataset benchmark, or an OpenOOD reproduction. This protocol is frozen before accessing the pet archives, annotations, images or any pet score. Preserve all earlier raw results.

## Source and fixed census

Use only the complete official Oxford-IIIT Pet **test** split, expected 3,669 JPEGs. The [Oxford VGG dataset page](https://robots.ox.ac.uk/~vgg/data/pets/) provides the official images and annotations archives, and the [torchvision OxfordIIITPet source](https://docs.pytorch.org/vision/2.0/_modules/torchvision/datasets/oxford_iiit_pet.html) gives the split parser and source MD5s. The [original dataset paper](https://robots.ox.ac.uk/~vgg/publications/2012/parkhi12a/parkhi12a.pdf) gives 3,669 test images across 37 breeds. Source archives only:

- `https://www.robots.ox.ac.uk/~vgg/data/pets/data/images.tar.gz`, required MD5 `5c4f3ee8e5d25df40f4fd59a7f44e54c`.
- `https://www.robots.ox.ac.uk/~vgg/data/pets/data/annotations.tar.gz`, required MD5 `95a8c909bbe2e81eed6a22bccdf3f68f`.

Follow only official redirects. Save complete archives, resolved URLs, byte counts, MD5/SHA-256 and download logs. If either official archive fails integrity or is unavailable, leave the population unscored; do not substitute a mirror or subset. Read `annotations/test.txt` from the verified annotations archive. Require exactly 3,669 unique image IDs, valid 1-based labels 1–37, all 37 classes, unique matching JPEG basenames in the verified image archive, and no missing/corrupt test image. Keep all test rows and preserve split rows sorted lexicographically by image ID, with original labels/species metadata. Never use trainval/list annotations or any pet image to train, choose a checkpoint, fit a detector/temperature, or calibrate a threshold. Breed/species labels serve only integrity and later explicitly descriptive analysis.

Decode each test JPEG with installed Pillow RGB conversion and resize directly to 32×32 using `Image.Resampling.BILINEAR`, no crop or augmentation. Save contiguous uint8 NHWC `[3669,32,32,3]`, filenames, labels, original dimensions, per-JPEG and resized-pixel SHA-256 and the cache SHA-256. Compare resized pixels against the existing CIFAR-100 training/validation/test pixels; reject exact overlap and record within-pet duplicates. Independently reconstruct every cached pixel and label from the two verified archives before GPU inference. The large-source-to-32 resize and pet/CIFAR animal-semantic overlap are important limitations, not controlled variables.
